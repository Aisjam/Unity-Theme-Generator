# Design rules

The visual identity consists of Base, Primary and Accent. Game feedback uses Actionable and Blocked.

- Base produces surfaces, elevated surfaces, outline, and readable text
- Primary is navigation and standard action identity
- Accent is focus and special emphasis
- Actionable is a recognised valid interaction
- Blocked is a forbidden or invalid attempted action
- Disabled is neutral rather than red

Style reference USS files provide a visual design language independently from colours. They share semantic selectors and are copied into the output folder on generation.

Check both UI Toolkit support and sufficient contrast on the final display. Glassmorphism and neumorphism presets are approximations without advanced background blur or drop shadows.
